## Functional Scope
This context applies to user-service API behavior across the full user lifecycle and authentication flows.
It includes user creation, user updates, and user deletion, along with user retrieval and validation of expected business rules for each operation.
It also covers authentication-related scenarios such as login, session handling, and token-based access behavior.
The goal is to keep user-domain features, tasks, and models aligned with real business outcomes, ensuring consistency between API contracts, scenario intent, and executable automation design.
