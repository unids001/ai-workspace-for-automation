## Functional Scope
This context applies to task-service API behavior across the task lifecycle and related workflow flows.
It includes task creation, task updates, task deletion, task retrieval, and validation of expected business rules for each operation.
It also covers workflow-related scenarios such as status transitions, assignment handling, and token-based access behavior when applicable.
The goal is to keep task-domain features, tasks, and models aligned with real business outcomes, ensuring consistency between API contracts, scenario intent, and executable automation design.
